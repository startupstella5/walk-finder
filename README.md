# Walk Finder

**Where should we walk?** A single-page web app to find the fairest meeting spot for a walking group, so nobody drives much farther than anyone else.

Built for the November Step Challenge 🥾

## Features

- Add friends with addresses, towns, or landmarks
- Filter by trail type and vibe (lake views, dog-friendly, stroller-friendly, etc.)
- Set daily step goals (5k/10k/15k)
- Interactive map with all spots ranked by fairness
- Shareable links — the group is encoded in the URL hash
- Live OpenStreetMap integration to discover nearby parks

## Usage

Open `index.html` in a browser, or visit the live site:

**https://startupstella5.github.io/walk-finder/**

No server required — everything runs client-side.
